📂 Tus Tareas de Borrado
⚙️ Configurar Tarea de Borrado
Configura los campos de abajo para ver el resumen exacto de la regla.
1️⃣ Nombre de la Tarea y Carpeta a Limpiar
Puedes escribir o pegar una ruta local (C:\..., D:\...) o de red (\\Servidor\Carpeta), o usar el botón Explorar.
2️⃣ ¿Cuándo se debe ejecutar el borrado? (Programación)
3️⃣ ¿Qué fechas de archivos quieres BORRAR? ("Que tengan la fecha tal hasta tal")
Ej. 1 = desde el día 1 del mes anterior.
Ej. 31 = hasta el último día del mes anterior (o pon 25 si solo quieres borrar del 1 al 25).
Ej. 30 borra todo archivo cuya fecha tenga más de 30 días respecto al día de ejecución.
4️⃣ Filtros y Reglas de Retención ("Y SOLO DEJA TAL intacto")
Déjalo vacío para borrar cualquier tipo de archivo, o separa por comas.
Usa * como comodín si solo quieres atacar ciertos nombres.
🛡️ Reglas de Protección — ¿Qué archivos NUNCA se deben borrar ("Solo deja tal")?
Cualquier archivo que coincida se salvará.
Estas extensiones jamás se tocarán.
Ej. Pon 15 para dejar intactos los archivos del día 15.
Ej. Pon 3 para conservar siempre los 3 más nuevos.
Ej. Pon 7 para no tocar nada de la última semana.
Si un archivo está entre estas 2 fechas, se conserva.

🖥️ Cómo funciona en tu Windows Server
✅ Modo 1: Programador de Tareas de Windows (Recomendado)

Al marcar la casilla "Registrar en el Programador de Tareas de Windows Server (schtasks)", cada tarea que guardas queda registrada en el sistema operativo Windows bajo la carpeta \AutoCleanerServer\.

Windows Server invocará automáticamente:
AutoCleanerServer.exe --run-task <ID_TAREA>
en modo silencioso (sin abrir ventanas) a la hora exacta configurada.

⚡ Modo 2: Demonio Continuo en Segundo Plano

También puedes iniciar el programa al arrancar Windows Server con el parámetro:

AutoCleanerServer.exe --daemon
En este modo queda residente en segundo plano sin ventana emergente y evalúa todas las tareas cada minuto.
